# The Loudest WER! | Team Guide / 团队协作与素材替换说明

**EN:** This quick guide covers GitHub collaboration, local preview, and where to replace artwork and sound.
**中文：** 本指南简要说明 GitHub 协作、本地预览，以及图片和声音素材的替换位置。

## 1. GitHub collaboration / GitHub 协作

**EN:** Push the complete project to the team repository so teammates and the teacher can access the source. A local commit is not visible to others until it is pushed. A GitHub repository does not automatically publish a playable website; online hosting requires a separate GitHub Pages setup.
**中文：** 将完整项目推送到团队仓库，团队成员和老师才能看到源文件。本地 Commit 后，其他人还看不到，直到 Push 到 GitHub。GitHub 仓库不会自动发布成可玩的网页；在线托管需要另外配置 GitHub Pages。

**EN:** Recommended flow: clone the team repository in GitHub Desktop → select the agreed base branch → create a task branch → edit and preview → review **Changes** → Commit → **Push origin** → open a Pull Request for review. Confirm branch and Write access with the team first.
**中文：** 建议流程：用 GitHub Desktop 克隆团队仓库 → 选择约定的基础分支 → 创建任务分支 → 修改并预览 → 检查 **Changes** → Commit → **Push origin** → 创建 Pull Request 请团队 Review。开始前先确认目标分支和 Write 权限。

**EN:** The current project folder is not itself a Git repository. If you are bringing these files into the team's clone, copy the project contents into the cloned folder and keep its `.git` folder.
**中文：** 当前项目文件夹本身不是 Git 仓库。若要把这份项目文件同步到团队克隆目录，请复制项目内容并保留克隆目录里的 `.git` 文件夹。

**EN:** GitHub Desktop's **Push origin** uploads your commits. GitHub Pages is a separate publishing step and may make the website publicly accessible. [Push guide](https://docs.github.com/en/desktop/making-changes-in-a-branch/pushing-changes-to-github-from-github-desktop) · [Pages guide](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)
**中文：** GitHub Desktop 的 **Push origin** 会上传提交；GitHub Pages 是单独的发布步骤，网页可能会对公众开放。[Push 说明](https://docs.github.com/en/desktop/making-changes-in-a-branch/pushing-changes-to-github-from-github-desktop) · [Pages 指南](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

## 2. Do I need to install an asset pack? / 需要单独安装素材包吗？

**EN:** No. There is no separate asset-pack installer. Images and sounds are regular project files inside `assets/`. Clone or download the **entire project**, including `assets/`; keep the folder structure unchanged. If you add or replace a shared asset, commit and push that file too.
**中文：** 不需要。素材包没有单独的安装程序，图片和声音就是 `assets/` 里的普通项目文件。克隆或下载时要获取**完整项目**，包括 `assets/` 文件夹，并保持原目录结构。新增或替换团队共用素材后，也要把素材文件一起 Commit、Push。

## 3. Preview locally / 本地预览

**EN:** In Terminal, open the project root (the folder containing `index.html` and `assets/`) and run:
**中文：** 在 Terminal（Mac）或终端（Windows）中进入项目根目录，也就是有 `index.html` 和 `assets/` 的文件夹，然后运行：

```sh
python3 -m http.server 8000
```

**EN:** Visit <http://localhost:8000/> and keep the terminal open. Stop with **Control + C**. If port 8000 is busy, use 8001 instead. `localhost` works only on your own computer; it is not a link to send to the teacher.
**中文：** 打开 <http://localhost:8000/>，预览时保持终端窗口开启；按 **Control + C** 停止服务。若 8000 端口被占用，可改用 8001。`localhost` 只在自己的电脑上有效，不能当作发给老师的网页链接。

## 4. Asset locations / 素材位置

**EN:** Keep the existing filename and path when replacing a file. If you rename or move it, update the matching HTML, CSS, or JavaScript reference.
**中文：** 替换素材时尽量保留原文件名和路径；如果改名或移动位置，也要更新对应的 HTML、CSS 或 JavaScript 引用。

| Asset / 素材 | File path / 文件路径 | Notes / 说明 |
|---|---|---|
| Home sunset and night backgrounds / 首页黄昏与夜晚背景 | `assets/backgrounds/home-sunset.png`<br>`assets/backgrounds/home-night.png` | **EN:** Keep the original 1672 × 941 ratio. The computer is painted into these backgrounds. **中文：** 保持原图 1672 × 941 比例；电脑已画在背景图里。 |
| Mystery Cat / 神秘猫 | `assets/pets/mystery-cat-guitar.png`<br>`assets/pets/mystery-cat-guitar-night.png` | **EN:** Transparent PNG; keep the canvas and subject placement similar across themes. **中文：** 使用透明 PNG；两种主题的画布和主体位置尽量一致。 |
| Orange Cat / 橘猫 | `assets/pets/orange-cat-christmas.png`<br>`assets/pets/orange-cat-night.png` | **EN:** Sunset and night versions. **中文：** 黄昏与夜晚各有一份。 |
| White Cat / 白猫 | `assets/pets/white-cat-christmas.png`<br>`assets/pets/white-cat-night.png` | **EN:** Sunset and night versions. **中文：** 黄昏与夜晚各有一份。 |
| Header logos / 顶栏 Logo | `assets/wer-christmas-ui/logo_sunset.png`<br>`assets/wer-christmas-ui/logo_night.png` | **EN:** Preserve transparency and aspect ratio. **中文：** 保留透明边缘和长宽比例。 |
| Home buttons / 首页按钮 | `assets/wer-christmas-ui/button_start_sunset_uniform.png`<br>`button_start_night_uniform.png`<br>`button_create_sunset_uniform.png`<br>`button_create_night_uniform.png`<br>`button_adopt_sunset_uniform.png`<br>`button_adopt_night_uniform.png` | **EN:** These six files are displayed; keep the 300 × 100 px canvas. **中文：** 网页显示这六个文件；画布保持 300 × 100 px。 |

| Studio background / 工作室背景 | `assets/backgrounds/seaside-park.png` | **EN:** Keep this filename; add the file here if it is missing. **中文：** 保留此文件名；如果目录里没有，请新增在这里。 |
| Pet list thumbnails / 宠物列表小图 | `assets/pets/cat.png`, `dog.png`, `bird.png`, `bunny.png`, `frog.png`, `fox.png` | **EN:** These are different from the large Home cat sprites. **中文：** 这组是宠物列表小图，与首页猫咪大图不同。 |

**EN:** To replace art, back up the old file, export the new image as PNG or sound as WAV, replace the matching file, refresh the page, then check that the asset appears in GitHub Desktop's **Changes**. Use only team-made or licensed material. The Home computer is already part of the wallpaper; no separate computer PNG is required.
**中文：** 替换时先备份旧文件，图片导出为 PNG、声音导出为 WAV，再覆盖对应文件并刷新网页，最后在 GitHub Desktop 的 **Changes** 中确认素材已加入。只使用团队自制或已获授权的素材。首页电脑已经包含在背景图里，无需另加电脑 PNG。
